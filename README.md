# 对话图片制作 · 网页版与安卓离线版

一个用于制作虚构聊天图片的非官方娱乐工具，提供浏览器网页版与安卓独立离线版。

## 功能

- 编辑聊天标题、用户头像和用户名，收藏常用用户。
- 添加文字、图片、模拟语音、红包、转账和好友成功通知。
- 添加微信表情及自定义表情图片。
- 生成普通截图和长截图，保存到手机。
- 查看图片生成历史，导出和导入聊天备份。

## 网页版

启用本仓库 GitHub Pages 后，可打开 [在线网页版](https://0x9527-eth.github.io/wxdh-android/)。

网页版包含常用用户、微信表情、自定义表情、好友成功通知、普通截图、长截图和图片历史。当前为桌面布局，安卓手机独立使用可下载 Releases 中的 App。

打开“对话设置”编辑内容，在聊天预览下方点击“生成图片”或“生成长截图”，在预览窗口下载 PNG；“图片历史”可打开之前生成的图片。历史、聊天、头像和收藏保存在当前浏览器本地，不会自动在不同设备或浏览器间同步。

电脑本地版与在线版的存储相互独立。迁移现有聊天时，先在旧页面导出聊天备份，再在在线页面导入。备份包含常用用户和自定义表情，不包含图片历史；重要历史图片请先下载。

## 安卓版安装与使用

适用于安卓 8.0 及以上。在本仓库的 Releases 页面下载安装包，用手机文件管理器打开 APK 安装。安装后应用名称为“对话图片制作”。

底部“编辑对话”用于编辑，“预览 / 生成”用于查看和保存图片。安卓 10 及以上可保存到相册；安卓 8 / 9 通过系统窗口选择保存位置。

聊天、收藏和图片历史保存在手机本地。更新时请覆盖安装；卸载应用或清除应用数据会清除这些本地记录。聊天备份不包含图片历史，重要图片请另行保存。

当前版本：1.0.2。已完成构建、签名及相关逻辑检查，尚未完成安卓真机全面验证，欢迎反馈问题。
